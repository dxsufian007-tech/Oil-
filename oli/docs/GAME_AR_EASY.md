# اللعبة بالعربية وبشكل أبسط (المرحلة 3.5)

## اللغة
- العربية هي اللغة الافتراضية: `lang="ar"` و`dir="rtl"`. الأرقام والمبالغ تبقى من اليسار لليمين داخل النص العربي.
- النصوص العربية مكتوبة في المصدر (`game-config.js`، `economy-config.js`، `building-config.js`) والباقي يمرّ عبر مترجم `ar.js` + `ar-dict.js` (قاموس + قواعد + مراقب DOM)، فلا تظهر كلمة إنجليزية للاعب.
- الإنجليزية خيار لاحق: `?lang=en` أو `localStorage oli-lang=en` (تستعملها الاختبارات القديمة).
- وضع المطوّر القديم (الشريط والـ30 مبنى): `?lab=1` أو `localStorage oli-labui=1`. (`?dev=1` بقي للجيولوجيا.)

## البدء والتعلّم
- يبدأ اللاعب بـ $10M. الدليل (`game-ui.js`): حفر بئر ← انتظار الحفر ← «ابدأ الإنتاج» ← خزان ← أنبوب ← تدفق ← بيع ← توسّع.
- البئر الجديد متوقف حتى الضغط على «▶ ابدأ الإنتاج».
- قائمة «البناء» أربع فئات: النفط، الأنابيب، التخزين، المعالجة. كل بطاقة: أيقونة، اسم، سعر، مساحة، وصف، زر «بناء» أو 🔒، و«؟ كيف يعمل».

## المستويات
1 بئر ← أنبوب ← خزان ← بيع · 2 توسّع (خزان متوسط، محطة ضخ صغيرة) · 3 معالجة (فاصل) · 4 المصفاة الصغيرة · 5 منتجات (خزانات صغيرة، كرة غاز) · 6 كل شيء (نقطة ربط، صمام، مصافٍ كبيرة).

## الوضع والأنابيب
- مكان مقترح تلقائيًا و«مكان آخر»؛ الشبح 🟢 صالح / 🔴 غير صالح مع السبب.
- الأنبوب: اضغط البداية ثم النهاية، مسار قصير تلقائي. الأنبوب المفتوح مسموح («غير متصل») ويُوصل لاحقًا («🔗 وصّل بمبنى») فيصبح «متصل».

## الاختبارات
`node test-game-ar.js` (Playwright، لمس حقيقي بحجم هاتف) و`.github/android/game-android.js` (محاكي أندرويد). الجهاز الحقيقي: لم يُختبر.
