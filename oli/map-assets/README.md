# Map-design assets (OLI EMPIRE)
Cut from the user-supplied art sheets (HUD icons, mountains/rocks, terrain textures, well pins, reserve platform, night background); backgrounds removed, scaled for phones, stored as WebP (~394 KB in all).
- `i-*.webp` HUD glyphs (transparent) · `pin-*.webp` well markers (green / gold / blue / red) · `platform.webp` reserve pumpjack platform
- `mtn-1..6.webp`, `rock-1..3.webp` 2.5D sprites · `tex-sand|rock|wadi|water.webp` 256² terrain textures · `night.webp` backdrop
The HUD frames (gold ring + navy panel) are drawn in CSS so they stretch crisply at any size.
